LoL FRIEND CLEANER - FREE PUBLIC BETA v1.1

LANGUAGE
The app starts in French. Click English (top-right) to switch the entire
interface, including warnings and confirmation dialogs, to English.
Click Francais to switch back.

QUICK START
1. Extract all ZIP files.
2. Open League of Legends and sign in.
3. Double-click LANCER.bat.
4. Click Detect friends and inspect the list.
5. Click Remove all only if you want to remove every friend.
6. Confirm, save the mandatory CSV backup, and type DELETE when prompted.
7. Detect again to verify.

CAUTION
Deletion is difficult to undo. The CSV is not an automatic restore function.
The local client API is unsupported and may change. No Riot password required.
This independent community app is not affiliated with Riot Games.
The beta has not yet been tested across all Windows configurations.
